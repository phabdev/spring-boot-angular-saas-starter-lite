# Roadmap

## Before the first paid release

- Complete independent security and dependency review against the intended deployment.
- Validate the extracted starter on a clean machine and record setup timing.
- Test real Stripe test-account checkout/webhooks/portal and production email-provider delivery.
- Finalize license, customer terms, support, privacy and refund handling.
- Connect source delivery, checkout and the consent-aware waitlist destination.
- Ask target Java/Angular developers to extend a real entity; measure setup success and recurring friction before expanding scope.

## Candidate improvements

Pagination, accessibility hardening, organization tenancy, additional email providers and an Agency licensing option. These are proposals, not purchased features or delivery commitments. No dates or lifetime-update promise are made.

## Deliberately outside V1

Kubernetes, microservices, multiple database engines, arbitrary role editors, no-code building, live billing operations and a hosted service.
